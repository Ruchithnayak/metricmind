# UX Guide

NOVA uses a decision-first layout.

- Command Center: what changed and what matters now.
- AI Analyst: ask a governed business question.
- Scenario Lab: test a lever before acting.
- Action Board: convert signals into prioritized moves.
- Root Cause Map: follow evidence to a driver.
- Forecast: show a transparent baseline with guardrails.
- Data Trust: expose quality and calculation checks.
