# MetricMind NOVA Test Plan

## Functional
- Login accepts the development credentials.
- Navigation switches between decision modules.
- Region and category filters update KPIs.
- Analyst answers supported questions.
- Scenario controls update the sensitivity output.
- CSV export creates a downloadable dataset.

## Governance
- Trust checks identify missing required fields.
- Duplicate transaction IDs are detected.
- Profit formula is checked against net revenue, cost and shipping.
- Forecast page labels its output as a baseline when backtesting is unavailable.

## UX
- Desktop navigation remains visible.
- Tablet layouts collapse multi-column sections.
- Mobile layouts stack decision cards and trust panels.
